Pelatihan Ulang Model

Pelatihan memakai seluruh stok keluar harian di basis data{% if t %} (s.d. {{ t | tgl_panjang }}){% endif %} dan data master bahan saat ini (harga, kemasan, masa simpan, kapasitas simpan, biaya kehabisan), lalu menjalankan alur penelitian:

  1. XGBoost global: pembagian data latih/validasi/uji 4 minggu terakhir, grid search dengan validasi silang rolling origin, σe dari galat di luar sampel.
  2. Q-Learning: satu Q-table per bahan, state dari IP, prediksi, stok hampir kedaluwarsa, dan penanda ROP; aksi kelipatan kemasan.
  3. Simulasi K1, K2, K3 pada 28 hari terakhir dan laporan Excel.
  4. Model produksi dilatih ulang dengan semua data, lalu menjadi model aktif.
